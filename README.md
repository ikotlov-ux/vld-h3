# VLD-H3

Программа расчёта баллов Ценности, Нагрузки и Нарушенности (V, L, D) экосистем ООПТ г. Москвы на гексагональной сетке H3, ведения многолетнего архива результатов по ООПТ и построения карт. ИПЭЭ РАН, лаборатория биогеоценологии.

Техническое задание: [docs/TZ_VLD_script.md](docs/TZ_VLD_script.md) (редакция 0.13).

## Состояние

| Этап | Содержание | Состояние |
|---|---|---|
| 1 | ядро: схема параметров, CLI, сетка H3, импорт V4, архив годичных результатов, разнолетняя сборка, квантование, выгрузка, каркас GUI (вкладки 1, 5, 6, 8) | выполнен (версия 0.1.0) |
| 2 | частные показатели 2026 г. по первичным данным (V, L, D), перенос площадных слоёв через сетку 5–10 м, фрагментация по патчам, разделы GUI на вкладках 2–4 | выполнен (версия 0.2.0) |
| 3 | карты: один параметр, пары 3 × 3, куб CIELAB, матрица решений | — |
| 4 | доводка GUI, справочники CSV/XLSX, руководство, проверка на Windows и macOS | — |

Частные баллы подаются двумя способами: импортом файла V4 или таблиц готовых баллов по `h3_id` (поля `v_*`, `d_*`, `load_cat`, `inv_n`) либо расчётом по первичным данным (этап 2). Если для показателя заданы первичные данные, он рассчитывается; остальные показатели берутся из импорта или остаются н/д.

Первичные данные этапа 2:

| Показатель | Вход |
|---|---|
| зональность `v_zon`, ёмкость `v_cap` | слой экосистем D2 (выделы с кодом типа), типология D3 (лист с полями «Тип» и «Зональность») |
| насекомые `v_ins` | таблица рейтингов площадок (OOZT, BIOTOP, PLOT, RATING) и координаты площадок |
| млекопитающие `v_mam`, низшие позвоночные `v_anam` | точки находок (XLSX/CSV, поля широты и долготы), справочники «вид → ФГ» |
| птицы `v_bird`, гидробионты `v_aqua` | единицы учёта и водоёмы с готовым числом ФГ или баллом |
| редкие растения `v_rare` | точки с категориями Красной книги |
| QBS `v_qbs` | значения по точкам и годам; пороги 250 и 350; перенос — ближайшая точка в той же ООПТ, последний год не позднее года расчёта |
| нагрузка `load` | фотографии с координатами, рекреационные объекты |
| инвазивные `d_inv` | точки растений (число растений в гексагоне) |
| фрагментация `d_frag` | слой D2, дорожно-тропиночная сеть и здания; классы лес, луг, кустарник, болота, вода, антропоген; ECON, ENN, SHAPE, CONTIG, PARA |

Слой GeoPackage указывается как `файл.gpkg::слой`; без указания слоя выбирается первый подходящий по геометрии и имени.

## Установка

Python 3.11–3.13:

```
pip install -r requirements.txt
```

Tkinter входит в стандартные сборки Python для Windows и macOS (python.org). Без Tkinter работает пакетный режим.

## Запуск

```
python vld_h3.py                                   # графический интерфейс
python vld_h3.py run --config params.json          # расчёт по файлу параметров
python vld_h3.py run --preset "2025 — воспроизведение V4" --set inputs.v4_path=V4.xlsx --set check.reference_path=V4.xlsx
python vld_h3.py import-v4 V4.xlsx --archive vld_archive.gpkg      # результаты 2025 г. в архив
python vld_h3.py archive-list --archive vld_archive.gpkg
python vld_h3.py export --archive vld_archive.gpkg --out out --rule last --xlsx
python vld_h3.py export --archive vld_archive.gpkg --out out --rule manual --manual "BIT=2025, KUS=2026"
python vld_h3.py transitions --archive vld_archive.gpkg --oopt IZM --y1 2025 --y2 2026 --out out
python vld_h3.py config --preset "2026 — базовый" --out params.json
python vld_h3.py selftest --v4 V4.xlsx --work test --bounds2026 "Границы ООЗТ.gpkg"
python vld_h3.py selftest2 --config params2026.json --work test2 --v4 V4.xlsx
python vld_h3.py defaults --out resources/defaults.json      # выгрузить встроенные справочники
```

Любой параметр файла JSON переопределяется ключом `--set раздел.поле=значение`. Один и тот же файл параметров в GUI и CLI даёт одинаковые таблицы атрибутов (П12).

## Встроенные наборы параметров

| Набор | Назначение |
|---|---|
| 2025 — воспроизведение V4 | частные баллы V4 без изменений, QBS 0 как число; V и D — совместные терцили Excel |
| 2025 — исправленный | балл инвазивных пересчитан по основному правилу, QBS 0 → н/д |
| 2026 — базовый | все частные показатели, основное правило инвазивных, QBS 0 → н/д |

## Автотесты этапа 1

| № | Проверка | Результат на V4 |
|---|---|---|
| П1 | сетка H3 разрешения 11 | 48 954 ячейки, множество `h3_id` и принадлежность ООПТ совпадают |
| П2 | терцили Excel и фиксированные пороги 2025 г. | V, L, D — 100 %; доли V 40,3 / 30,9 / 28,8 %, D 43,6 / 47,4 / 9,0 % |
| П3 | PERCENTRANK.INC | совпадение с независимой реализацией; книга с формулами для проверки в Excel |
| П5 | набор «2025 — исправленный» | отличие от V4 ровно в 1 273 гексагонах по V и 64 по D |
| П10 | повторяемость | одинаковый SHA-256 таблицы атрибутов |
| П11 | архив 11 ООПТ 2025 г. + 3 ООПТ 2026 г. | 14 ООПТ в одной выгрузке, баллы 2025 г. без изменений; замена одного среза не затрагивает остальные; режим II; матрицы переходов |

В тесте П11 баллы 3 ООПТ 2026 г. (Кусково, Покровское-Стрешнево, Царицыно) условные (случайные с фиксированным зерном): проверяется механика архива, а не оценки.

## Автотесты этапа 2

Команда `selftest2` выполняет расчёт по файлу параметров с первичными данными 2026 г. и проверки:

| № | Проверка | Результат на данных 2026 г. |
|---|---|---|
| П4 | фрагментация: патчи природных классов | 625 патчей (лес 388, луг 51, кустарник 145, болота 41), 3 139,7 га — совпадает с эталонным расчётом; с присоединением мелких контуров — 625 патчей, присоединено 44 контура |
| П4 | инвазивные: число растений в гексагоне | совпадение с V4 в 17 710 общих гексагонах — 100 % |
| П7 | производительность | 18 ООПТ, 80 954 гексагона: 17,5 с, пиковая память около 1,3 ГБ |
| П9 | ошибки входных данных | переставленные координаты, точки вне района и далее 10 км, несопоставленный вид, некорректная геометрия D2, отсутствующие поля, файлы и блоки — сообщения без аварийного завершения |

## Справочники

`resources/defaults.json` содержит справочник ООПТ и синонимов, наборы параметров, пороги 2025 г., таблицу H3, справочники «вид → ФГ», встроенную таблицу зональности, соответствие «тип экосистемы → BIOTOP», матрицу контраста ECON и знаки метрик фрагментации. При отсутствии файла используются встроенные значения; синонимы ООПТ из файла дополняют встроенные.

## Архив годичных результатов

`vld_archive.gpkg`: слой `vld_yearly` (ключ `oopt_id, calc_year, h3_id`), таблицы `runs_meta` (параметры, пороги, SHA-256 входных файлов по каждому срезу) и `oopt_dict` (справочник синонимов ООПТ), по выбору `oopt_bounds`. Запись выполняется через временную копию с последующей заменой файла.

## Данные

Входные данные (в том числе координаты видов Красной книги) в репозиторий не включаются (п. 4.7 ТЗ). Логотипы организаций размещаются пользователем в `resources/logos` (п. 5.2 ТЗ).
