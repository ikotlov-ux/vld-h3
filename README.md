# VLD-H3

Программа расчёта баллов Ценности, Нагрузки и Нарушенности (V, L, D) экосистем ООПТ г. Москвы на гексагональной сетке H3 и построения карт. ИПЭЭ РАН, лаборатория биогеоценологии.

Техническое задание: [docs/TZ_VLD_script.md](docs/TZ_VLD_script.md) (ред. 0.12).

## Состояние

Разработка ведётся в четыре этапа (разд. 16 ТЗ):

| Этап | Содержание | Состояние |
|---|---|---|
| 1 | ядро в пакетном режиме: схема параметров, CLI, сетка H3, импорт V4, архив годичных результатов, квантование, выгрузка | в работе |
| 2 | частные показатели 2026 г. по первичным данным | — |
| 3 | карты | — |
| 4 | декларативный GUI, справочники, руководство | — |

## Запуск

```
python vld_h3.py                      # графический интерфейс
python vld_h3.py run --config params.json
python vld_h3.py --help
```

Зависимости: Python 3.11–3.13, geopandas ≥ 1.0, shapely ≥ 2.0, pyogrio, pyproj, h3 ≥ 4.0, numpy, pandas, openpyxl; для GUI — Tkinter.

## Данные

Входные данные (в том числе координаты видов Красной книги) в репозиторий не включаются (п. 4.7 ТЗ). Логотипы организаций размещаются пользователем в `resources/logos` (п. 5.2 ТЗ).
