## 5. Интерфейс

Проверено в среде Л при 1366 × 768: все вкладки прокручиваются, разделы сворачиваются, сводки и флажки отображаются; окна предпросмотра (XLSX 2026 г., 324 строки) и справочников (матрица ECON, справочник ФГ млекопитающих) читаемы. В среде W окно строится с коэффициентом масштаба 1,0 при 96 dpi, начальный размер 1181 × 820, минимальный 1025 × 700. Масштаб 125–200 % проверяется на рабочем месте пользователя: размеры элементов пересчитываются по фактическому dpi.

## 6. macOS

Проверено в GitHub Actions (`macos-latest`: macOS 26, arm64; файл `.github/workflows/selftest.yml`, запуск 43253622183) той же командой `selftest4`: 16 из 16, включая графические проверки П12.3–П12.8 и пробел в конце имени папки; SHA‑256 совпадает с Linux и Windows. Отчёт `selftest4_report.json` сохраняется как артефакт сборки. Проверка на Intel‑Mac и с экраном Retina на рабочем месте пользователя не проводилась.
